One-line roast of a smart fridge for the make.fun bounty
"Fridge Roast: One Line, Biggest Laugh" ($5). The entry roasts the
fridge's grocery auto-order: it couldn't see past the jam, ordered eggs
on its own, and now calls the mess "proactive inventory management".

## Entry

> My smart fridge auto-ordered eggs because it couldn't see past the jam, so now I own forty-eight eggs and an appliance that calls it 'proactive inventory management.'

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` and verifies the file is
byte-identical to the entry (1–200 characters, single line, UTF-8).
